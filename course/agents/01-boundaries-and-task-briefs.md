# Write a bounded brief

Optional agent lab · 20 to 30 minutes

## Try

Take the request "improve my project". Rewrite it to name one observable behavior, one allowed file, two acceptance cases and a no-dependency rule.

## Build

Compare your brief with the one in lesson 3.4. Without an agent, exchange it with your future self: close it for a session, then identify what you would edit from its wording alone.

## Verify

A reader can identify the permitted diff without guessing. Reject a brief that changes stored data without specifying which data and how.

Save your observations in an evidence note. If you revealed an answer, repeat with a new input before marking the practice complete. No live provider is required.
