# Trace a proposed function

Optional agent lab · 20 to 30 minutes

## Try

Read exercises/3.4/proposal.md without its review key. Trace "A B" through every transformation.

## Build

Write the intermediate value after strip, lower and replace. Run that trace as a scratch script.

## Verify

The observed a-b differs from the required a b. Name the exact contract violation; do not reject the proposal merely because an agent wrote it.

Save your observations in an evidence note. If you revealed an answer, repeat with a new input before marking the practice complete. No live provider is required.
