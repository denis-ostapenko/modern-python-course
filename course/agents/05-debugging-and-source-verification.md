# Compare two hypotheses

Optional agent lab · 20 to 30 minutes

## Try

Use parse_count("hello") from lesson 2.1. Ask for two causes and one distinguishing observation, or compare conversion failure with a wrong sign condition yourself.

## Build

Inspect raw before int, then run with "-1". Link the int behavior to the official Python documentation rather than relying on a confident explanation.

## Verify

The observations distinguish text that cannot convert from a converted number that violates a domain rule.

Save your observations in an evidence note. If you revealed an answer, repeat with a new input before marking the practice complete. No live provider is required.
