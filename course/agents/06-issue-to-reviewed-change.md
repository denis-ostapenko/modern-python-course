# Carry one issue to handoff

Optional agent lab · 20 to 30 minutes

## Try

Choose a small capstone defect. State its current and expected behavior and make a Git checkpoint before asking for a proposal.

## Build

Use a live agent or the stored tag proposal as a rehearsal. Inspect all changed files, run the relevant cases and reference checks, then write a handoff with the accepted scope, rejected suggestion, known limit and recovery commit.

## Verify

Your evidence records who or what proposed the change, what you decided, which commands ran and which revision they checked. A simulated proposal is labelled as such.

Save your observations in an evidence note. If you revealed an answer, repeat with a new input before marking the practice complete. No live provider is required.
