# Core Terms

Status: initial reference entries

## Program

A sequence of instructions and data organized to produce behavior when a runtime executes it.

## Source code

Human-readable text written in a programming language. A `.py` file contains Python source code.

## Programming language

A defined system of syntax and meaning used to express computations and program behavior.

## Interpreter

Software that reads program instructions and arranges for them to be executed. CPython compiles Python source to bytecode and executes that bytecode in its virtual machine, so the beginner label "interpreter" describes a role rather than every internal step.

## Syntax

The structural rules that determine whether text forms valid code.

## Semantics

The behavior and meaning of valid code.

## Runtime

The software and environment in which a program executes.

## Test

An explicit example or check that compares required behavior with observed behavior.

## Agent

Software that can pursue a goal through multiple steps, use permitted tools, observe results, and adjust its next action.

## Related entries

Expression, statement, value, object, type, name, function call, exception, traceback, and acceptance criterion.
