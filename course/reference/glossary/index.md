# Glossary

Use the definition that helps you read the next line of code. Return to the linked lesson when a short definition is not enough.

| Term | Meaning | First use |
| --- | --- | --- |
| Source | Instructions saved as text | First run |
| Interpreter | Program that executes Python | Local workspace |
| Expression | Code evaluated to produce a value | Values |
| Statement | An instruction such as assignment or return | Values |
| Value / type | A piece of data / its kind | Values |
| Name / assignment | A reference to a value / binding that name | Values |
| Condition | Expression interpreted as true or false | Decisions |
| Collection | Value containing related values | Lists and records |
| Mutation | Changing an existing object's contents | Lists and records |
| Iteration | One step through repeated work | Loops |
| Parameter / argument | Input name in a definition / actual value at a call | Functions |
| Return | Send a result back to the caller | Functions |
| Scope | Region where a name can be resolved | Functions |
| Exception | An event interrupting ordinary execution | Debugging |
| Traceback | Recorded call path to an exception | Debugging |
| Boundary | Place where external input or output meets core behavior | Files |
| Assertion | Check that a claimed condition is true | Tests |
| Regression | Behavior that worked but breaks after a change | Tests |
| Fixture | Prepared data or state for a repeatable check | Tests |
| Module | Importable Python file | Modules |
| Dependency | External package required by a project | Modules |
| Environment | Selected interpreter and installed packages | Modules |
| Lockfile | Record of resolved dependency versions | Modules |
| Dataclass | Class with generated data-record methods | Types |
| CLI | Interface controlled through terminal arguments | Commands |
| Repository | Files and their version history | Git |
| Commit | Deliberate snapshot of staged content | Git |
| Branch | Named line of versioned work | Git |
| Diff | Representation of changes between versions | Git |
| CI | Automated checks run for a shared revision | Collaboration |
| Agent | Software that can pursue tasks through tools | Agent review |
| Acceptance criterion | Observable condition defining a requested result | Agent review |

See [core terms](01-core-terms.md) for a longer explanation of source, syntax and execution.
