# About this course

Modern Python: From First Run to Reviewed Change

By Denis Ostapenko · Edition 1.0 · September 2026

I want you to finish this course able to make a small change, explain why it works, and recover when it does not. Running code is the start. Reading the result and deciding what to do next is the skill we will keep practising.

The guided project records time spent on activities. Your final project uses a different problem. You will work with ordinary Python files, inspect tests and diffs, and review an agent's proposal with the same attention you would give any other suggested change.

## What the course includes

Seventeen milestones, a browser first run, a downloadable local workspace, fourteen independent exercise packages, thirty recovery checkpoints, a complete Daybook reference, a local review-conflict simulation, an independent capstone assessment kit, optional labs, and compact references.

Plan around 16 to 21 hours of active core lessons, plus an independent project. Allow approximately 8 to 12 hours for a first capstone, with extra elapsed time if you arrange a human review. These are planning estimates, not measured learner completion times. Setup and recovery vary by device and prior experience.

## What completion means

The browser first lesson checks current-source execution and retains your repair explanation. Later milestones are self-recorded after local checks and reflection. The site does not inspect your computer, automatically grade prose, or issue an accredited certificate.

A local review simulation is explicitly different from a live review by another person. Both support practice; your final evidence must name which route you used.

## Storage and network

Drafts and notes are stored on your device when browser storage works. Export them to keep a portable copy. There is no account system, analytics SDK, model gateway, or automatic submission of code to an AI provider. The website and Python runtime files load from the same published site. The initial local tool installation needs internet. GitHub collaboration and an optional live agent have their own accounts and network requirements.
