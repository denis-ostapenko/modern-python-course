# Your real workspace

0.2 · 35 to 60 minutes · Local workspace

Move the program into a folder you can reopen and control.

## Try

Complete the [setup guide](../setup.md), then download the learner workspace from the course toolbar. Extract the ZIP. In VS Code select File > Open Folder and choose the extracted learner-workspace folder, not main.py. Select Terminal > New Terminal and run `uv sync --frozen`, then `uv run python main.py`.



## Understand

The folder is your project. Explorer lists its files; selecting `main.py` opens source in the editor. The terminal accepts commands. `uv run python main.py` starts Python inside this project's environment and asks it to execute the file.

| Surface | What belongs there |
| --- | --- |
| Explorer | Choose a file or see the folder tree |
| Editor | Change and save source text |
| Terminal | Type uv or Git commands and read program output |
| Interpreter | Execute Python; it is a program, not the editor |

Press Save before a local run. A browser Run captures its editor automatically; a local terminal command reads the saved file. The Problems panel can contain editor diagnostics. Your printed program output is in the terminal used to run it.

The starter's `uv.lock` records dependency versions. `.venv` is the project environment generated by uv. You do not need to edit either file. Choose Python: Select Interpreter from the Command Palette and select this folder's `.venv` when the Python extension asks.

```python
category = "reading"
minutes = 25
print(f"{category}: {minutes} minutes")
```

Expected output:

```text
reading: 25 minutes
```

## Build

1. Run `uv run python tools/start_git.py` to create the local baseline. This creates no remote account.
2. Run `uv run python tools/check_environment.py`. Every item must pass, including the repository baseline.
3. Open main.py and change 25 to 30. Save. Run `uv run python main.py`; expect `reading: 30 minutes`.
4. Run `git diff -- main.py`. The removed line starts with `-`; the added one with `+`. Describe the single change.
5. Restore only this practice edit with `git restore -- main.py`. Run again and expect 25.
6. Close VS Code, reopen the same folder, and run again without repeating installation.

If the helper reports an existing repository, inspect `git status` instead of reinitializing. If Git asks who you are later, use the local identity setup in lesson 3.2. The supplied first commit uses an exercise-only identity.



## Verify and explain

Run the environment diagnostic after restoring main.py. Explain where you typed the command, where you edited the number, and which file the command read. A successful environment check alone does not assess that explanation.
