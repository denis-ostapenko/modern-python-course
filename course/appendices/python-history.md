# A Short History of Python

Status: optional explanation

Read this after the first successful run if you want context about the language's origin.

Guido van Rossum began implementing Python at CWI during the 1989 Christmas holidays. Work with the ABC language influenced Python's readable syntax, indentation-based grouping, and high-level data types. A need for an extensible scripting language in the Amoeba distributed operating system also shaped the design. Python was posted publicly to USENET in February 1991.

The historical detail is useful context, but it is not required to write, run, test, or debug a Python program.
